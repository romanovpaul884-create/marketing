# SEO — главный скил агентства

**Вызов:** `/seo $1 $2`

Оркестрирует субагентов команды для типовых SEO-задач.

## Команды

| Команда | Что делает | Кто работает |
|---------|------------|--------------|
| `/seo niche <url>` | Ресёрч ниши, ЦА, конкурентного поля на старте | `niche-researcher` |
| `/seo semantics <url или ниша>` | Сбор и кластеризация семантического ядра | `semantic-core` (+ `serp-analyst`) |
| `/seo serp <запрос>` | Разбор поисковой выдачи по запросу | `serp-analyst` |
| `/seo audit <url>` | Полный аудит сайта (техника + контент + коммерция) | `tech-auditor`, `content-strategist`, `commercial-factors` параллельно |
| `/seo tech <url>` | Только технический аудит | `tech-auditor` |
| `/seo commerce <url>` | Только коммерческие факторы | `commercial-factors` |
| `/seo competitor <url>` | Глубокий разбор конкурента | `competitor-researcher` |
| `/seo content-plan <проект>` | Контент-план на 1–3 месяца | `content-strategist` |
| `/seo brief <запрос или кластер>` | ТЗ копирайтеру | `content-strategist` (+ `serp-analyst`) |
| `/seo links <url>` | Ссылочная стратегия и анализ профиля | `link-strategist` |
| `/seo local <url>` | Локальный SEO-аудит (Я.Бизнес + GBP) | `local-seo` |
| `/seo schema <url>` | Разметка schema.org | `schema-engineer` |
| `/seo report <проект>` | Отчёт клиенту по выгруженным данным | `analytics-reporter` |

## Логика оркестрации

### Новый клиент / новый проект
Запускай в таком порядке:
1. `/seo niche <url>` — понять что продвигаем
2. `/seo audit <url>` — что сейчас на сайте
3. `/seo semantics <url>` — собрать ядро под подтверждённые направления
4. `/seo competitor` × 2–3 — разобрать главных конкурентов
5. `/seo content-plan` — спланировать работу на 3 месяца

### Регулярная работа (ежемесячно)
1. `/seo report` — отчёт клиенту
2. На основе отчёта — приоритеты следующего месяца
3. По мере выпуска новых посадочных — `/seo brief` под каждый кластер

### Специализированные задачи
- Раздел сильно проседает → `/seo audit` + `/seo competitor` (ближайший в выдаче)
- Запускаем новый раздел → `/seo niche` (на этот раздел) + `/seo semantics`
- Хотим в Я.Карты → `/seo local`

## Где хранить артефакты

Всё по проекту — в `projects/<имя_проекта>/`:

```
projects/<проект>/
├── research/      # ниша, ЦА (niche-researcher)
├── semantics/     # core.csv, clusters.md (semantic-core)
├── serp/          # разборы по запросам (serp-analyst)
├── competitors/   # разборы конкурентов (competitor-researcher)
├── audits/        # tech, commercial аудиты
├── briefs/        # ТЗ копирайтерам (content-strategist)
├── content-plan.md
├── links/         # ссылочная стратегия (link-strategist)
├── local/         # локальный SEO (local-seo)
├── schema/        # разметка по страницам (schema-engineer)
├── data/          # выгрузки из GSC/GA4/Метрики (от клиента)
└── reports/       # отчёты клиенту (analytics-reporter)
```

## Принципы

- **Сначала ниша, потом семантика.** Без понимания ЦА `semantic-core` соберёт мусор.
- **Параллельно где можно.** Аудит = параллельный запуск 3 агентов, не последовательно.
- **Один артефакт — один автор.** Не дублируй работу разных агентов на одном файле.
- **Никаких чёрных методов.** Накрутки, PBN, AI-простыни без редактуры — не предлагаются.
- **Яндекс ≠ Google.** В Рунете всегда учитываем оба, у каждого свои факторы.
