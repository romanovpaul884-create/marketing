# SEO-агентство — рабочее пространство

Это репозиторий для работы SEO-агентства. Основная задача — автоматизация рутины: сбор семантики, аудиты, ресёрчи конкурентов, ТЗ копирайтерам, отчёты клиентам.

## Команда субагентов

В `.claude/agents/`:

| Агент | Роль |
|-------|------|
| `niche-researcher` | Исследует нишу, ЦА, поводы покупки, конкурентное поле на старте проекта |
| `semantic-core` | Собирает и кластеризует семантическое ядро |
| `serp-analyst` | Разбирает поисковую выдачу по конкретному запросу |
| `competitor-researcher` | Глубоко разбирает конкретный сайт-конкурент |
| `tech-auditor` | Технический SEO-аудит (краулинг, индексация, CWV, robots, sitemap) |
| `content-strategist` | Контент-планы, ТЗ копирайтерам, оценка E-E-A-T |
| `link-strategist` | Анализ ссылочного, аутрич-планы |
| `local-seo` | Локальное SEO (Я.Бизнес, GBP, NAP, отзывы) |
| `schema-engineer` | Разметка schema.org |
| `commercial-factors` | Коммерческие факторы (важно для Яндекса) |
| `analytics-reporter` | Отчёты клиентам по выгрузкам из GSC/GA4/Метрики |

## Главный скил

`/seo <команда> <аргумент>` — оркестрирует команду под типовые задачи. Полный список команд см. в `.claude/skills/seo/SKILL.md`.

## Структура проектов

Каждый проект клиента живёт в `projects/<имя_проекта>/`:

```
projects/<проект>/
├── research/      # ресёрч ниши и ЦА
├── semantics/     # семантическое ядро
├── serp/          # разборы выдачи
├── competitors/   # разборы конкурентов
├── audits/        # технические и коммерческие аудиты
├── briefs/        # ТЗ копирайтерам
├── content-plan.md
├── links/         # ссылочная стратегия
├── local/         # локальное SEO
├── schema/        # разметка
├── data/          # выгрузки из аналитики (от клиента)
└── reports/       # ежемесячные отчёты
```

## Принципы работы

1. **Сначала ниша, потом семантика.** Не лезь в `semantic-core` без `niche-researcher` или подтверждённого брифа.
2. **Яндекс ≠ Google.** Под Рунет всегда учитываем оба поисковика. Коммерческие факторы и поведенческие — для Яндекса. Ссылки и E-E-A-T — для Google.
3. **Никаких чёрных методов.** PBN, накрутка отзывов/поведенческих, биржи мусорных ссылок, AI-простыни без редактуры — не предлагаем.
4. **Артефакты — в файлы.** Не держи отчёт в чате. Сохраняй в `projects/<проект>/`, чтобы можно было передать клиенту, копирайтеру или вернуться через 3 месяца.
5. **Один файл — один автор-агент.** Не размазывай тему между агентами. Если задача на стыке — назначай ответственного, остальные дают вход.
6. **Параллельно где можно.** Аудит = `tech-auditor` + `commercial-factors` + `content-strategist` запускаются одновременно.

## Что нужно от клиента (типовой набор)

- Доступ в Я.Метрику и GSC (на чтение)
- Доступ в Я.Бизнес и GBP (на редактирование, если ведём локалку)
- Брендбук / стайлгайд (если есть)
- Контакт ЛПР (за 1 день решает 80% вопросов)
- Контакт копирайтера / разработчика (для исполнения ТЗ)
