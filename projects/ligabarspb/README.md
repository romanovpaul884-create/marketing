# Проект: Лига Универ — раздел /events/ (мастер-классы)

**Сайт**: https://ligabarspb.ru/
**Раздел**: https://ligabarspb.ru/events/
**Регион**: СПб (основной), Москва (вторичный)
**Запущен**: 2026-04-29

## Текущая задача

Продвижение мастер-классов: ресёрч раздела + сбор семантики, заточенной на конверсию в заказы.

## Что сделано (2026-04-29)

- ✅ Ресёрч ниши, ЦА, поводов покупки, конкурентного поля → `research/niche-events.md`
- ✅ Карта семантических кластеров (13 кластеров) → `semantics/clusters.md`
- ✅ Список запросов в CSV для прогона через Wordstat → `semantics/core.csv`
- ✅ Карта посадочных + roadmap внедрения → `semantics/gaps.md`

## Главные выводы

1. **70% конверсионного спроса генерируется поводом**, а не продуктом. Самые ценные кластеры — "на корпоратив", "на день рождения", "на девичник", "выездной бар", "подарочный сертификат". На сайте ни одной из этих посадочных нет.
2. **Прямой бренд-конкурент** — `ligashow.ru` (созвучное имя, выездной формат). Лига Универ должна явно позиционироваться против него.
3. **Москва без отдельного домена/поддомена тянет плохо** — гео Яндекса бьёт. Решение нужно с клиентом.
4. **Цены не показаны на сайте** — критично для коммерческих факторов и решения покупателя. Нужно открыть хотя бы коридоры.
5. Видны **5 ТОП-приоритетных посадочных к созданию**: корпоратив, ДР, девичник, выездной формат, сертификаты.

## Что нужно от клиента (для следующего шага)

1. Прайс-коридоры на корп / выезд / сертификат — открыть на сайте
2. Кейсы (фото + отзывы) с прошедших ивентов
3. Решение по Москве: отдельный домен, поддомен, или оставить как есть с региональным рерайтом
4. Прогон ядра через Wordstat / Keys.so → проставить частотности
5. Подтверждение размещения на bantikov.ru (это Лига Универ или однофамильцы из ligabar.ru?)

## Следующие шаги (после ответов клиента)

2. `competitor-researcher` — глубокий разбор `ligashow.ru` + `culinaryon.spb.ru`
