## Главные выводы

1. **70% конверсионного спроса генерируется поводом, а не продуктом** — самые ценные кластеры закрывают повод (корпоратив, ДР, девичник, мальчишник), и **на сайте таких посадочных нет**.
2. **Лига Универ — единственный игрок с лофтом + барной экспертизой**. Все конкуренты делают что-то одно: либо выезд (ligashow), либо кулинарка с барной активностью (culinaryon), либо агрегатор. Это уникальная позиция.
3. **5 ТОП-приоритетных гэпов**: `/events/na-korporativ/`, `/events/na-den-rozhdeniya/`, `/events/na-devichnik/`, `/events/sertifikat/`, переработка `/services/vyezdnoy-bar/`.
4. **Я.Бизнес карточка лофта — самый быстрый рычаг** (колдунщик "Организации" активен по всем 5 ключевым запросам, 30% CTR).
5. **6-месячный план выхода в топ-3-7 СПб реалистичен** при бюджете 600-1100 тыс ₽ старт + 60-120 тыс/мес.
