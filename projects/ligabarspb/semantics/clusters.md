## Логика разделения

Кластеры построены по **интенту + посадочной**, а не только по словам. Один кластер = одна посадочная страница.

Интенты:
- 🔴 **commercial-product** — "хочу мастер-класс, понимаю продукт"
- 🟠 **commercial-occasion** — "хочу что-то на повод, продукт ещё не выбрал" (HRV для конверсии!)
- 🟡 **commercial-gift** — "хочу подарить впечатление"
- 🟢 **info** — "хочу узнать / научиться сам"
- ⚪ **brand** — "ищу именно Лигу Универ"
