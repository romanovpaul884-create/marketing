## Универсальный шаблон для всех продуктовых страниц

Применяется к каждой существующей продуктовой странице (Shake, Muddle, классические, латте-арт, испанские вина, китайский чай, кофе в турке и пр.).

### Структура страницы (H1 → блоки)

1. **H1** — точно по pillar-запросу, естественно встроенный город (СПб / Санкт-Петербург)
2. **Hero-блок**: 1 ключевая фотография (не сток!), цена/коридор цен, 3 ключевых факта (длительность, гостей, формат), 2 CTA (бронь даты + сертификат в подарок)
3. **Что вы будете делать** — 4-7 шагов программы с фото / иллюстрацией каждого
4. **Что приготовите** — список конкретных коктейлей/вин/блюд + фото
5. **Кто ведёт** — карточка ведущего/бармена с фото, регалиями, опытом (E-E-A-T!)
6. **Где проходит** — фото лофта (5+ фото), адрес, как добраться, парковка
7. **Сколько стоит** — таблица: формат / число гостей / цена + ссылка на сертификат
8. **Под какие поводы подходит** — карточки-ссылки на ивент-посадочные (корпоратив / ДР / девичник / мальчишник)
9. **Отзывы** — минимум 6 отзывов с фото, с аватаркой, с датой. Желательно — встраивать виджет с Я.Бизнеса (трастовый сигнал)
10. **FAQ-блок** — 6-10 вопросов с ответами в первых 50 словах (для AI Overviews / Нейро). Со schema.org FAQPage
11. **Бронь / форма** — короткая (имя + телефон + дата + комментарий)
12. **Sticky CTA-кнопка** на мобиле (75% трафика идёт с мобилы)

### Объём
- Категории (K1, K2, K3, K4): **1800–2200 слов**
- Продукты (Shake, Muddle, Латте-арт и т.д.): **1200–1500 слов**

### Schema.org разметка (обязательно)

```jsonld
- Service (на категории)
- Product + Offer + AggregateRating (на продуктовых)
- BreadcrumbList (везде)
- FAQPage (на каждой странице, где есть FAQ)
- LocalBusiness/EventVenue (на /events/ или в footer)
- Person (для ведущего)
```

Передать `schema-engineer` для генерации по каждой странице.

### Типичные проблемы, которые надо чинить

- Title и meta description — должны включать pillar-запрос + СПб + USP в 60/160 знаков
- Внутренняя перелинковка — каждая продуктовая ссылается на свою категорию, hub, и 2-3 ивент-посадочные
- Картинки — alt-теги по семантике (не "IMG_2345.jpg")
- INP / LCP — измерить, типичная проблема таких сайтов — тяжёлые слайдеры на главной

## Точечные планы по самым важным страницам

### 1. `/events/kokteylnye-master-klassy/` — pillar категории K1

**Текущее**: ~7-8 в Я.СПб, страница есть, но тонкая.
**Цель**: топ-3 за 6-8 недель.
**Шаги**:
1. Расширение контента до 2000 слов: история коктейльного движения в СПб (E-E-A-T от Лиги Универ как школы), описание форматов (Shake/Muddle/Классика — как разница), карточки трёх продуктов с фото, блок "под повод", блок цены, FAQ
2. **Добавить FAQ-блок** (10 вопросов): "Сколько длится мастер-класс?", "Сколько гостей?", "Что входит в стоимость?", "Можно ли с детьми?", "Что подарить мужу-любителю коктейлей?", "Можно ли заказать выезд?", "Можно ли купить сертификат?", "Какие коктейли вы готовите?", "Можно ли заказать на корпоратив?", "Как забронировать?"
3. **Добавить блок "Под какой повод"** с карточками-ссылками: Корпоратив / Девичник / Мальчишник / ДР / Свадьба → пока ведут на 404, потом будут жить ивент-посадочные
4. **Добавить блок "В подарок"** с CTA на сертификат
5. **Schema**: Service + FAQPage + AggregateRating
6. **Внутренняя ссылка** с главной + с /events/ + с похожих категорий (вино, кофе) — формат "вместе берут"

### 2. `/services/vyezdnoy-bar/` — K10

**Текущее**: ~5 в Я.СПб, но проигрывает Ligashow / Bar-Max / Welcomebar.
**Цель**: топ-5 за 8-12 недель.

Главная проблема: **Ligashow побеждает** потому что у них:
- Возраст домена с 2002 года
- Глубже структура (отдельные посадочные на каждый формат: коктейль-бар, винное казино, виски-дегустация, молекулярка, флер-шоу, крио-бар, кофе-принтер)
- Чёткие пакеты с ценами (1.5-3 часа, 10-200 чел)

**Что делаем**:
1. **Переработать страницу полностью** под транзакционный лендинг
2. **Добавить пакеты**: "Базовый бар" (10-30 чел), "Корпоративный" (30-100), "Премиум с шоу" (любой объём) — каждый с ценой и составом
3. **Видео** (1-2 минуты) — коктейльное флер-шоу или процесс выезда
4. **Портфолио мероприятий** — минимум 8 кейсов с фото, числом гостей, форматом
5. **Внутренняя перелинковка**: страница ссылается на ивент-посадочные (свадьба, корпоратив, ДР)
6. **Дизамбигуэйшн от Ligashow** — "Чем мы отличаемся от других выездных баров СПб" — мы школа, поэтому формат не просто "бармен наливает", а реально учим гостей. Это уникальное позиционирование.
7. **Микроразметка**: Service + Offer + AggregateRating

### 3. `/events/master-klass-latte-art/` — рассинхрон URL

**Действие**: 301-редирект на `/events/kofeynye-master-klassy/master-klass-latte-art/` + обновить все внутренние ссылки. Без потерь позиций — редирект сохранит ссылочный вес.

### 4. `/events/` — hub раздела

**Сейчас**: просто списком 5 категорий.
**Цель**: hub под повод — главный хаб для всех ивент-посадочных.

**Что добавляем**:
1. Фильтр "По поводу": Корпоратив / ДР / Девичник / Мальчишник / Свадьба / Подарок / Просто весело
2. Фильтр "По продукту": Коктейли / Вино / Кофе / Чай / Виски / Микс
3. Слайдер "Кейсы наших мероприятий"
4. Блок "Топ-3 формата для подарка"
5. Hero-видео (15-30 сек) — атмосфера лофта + коктейльное шоу
6. Schema: WebPage + ItemList + LocalBusiness

### 5. Категории K2 (вино), K3 (кофе), K4 (чай) — расширение продуктовой линейки

| Кластер | Существует | Добавить |
|---------|------------|----------|
| K2 вино | Искусство дегустации, испанские | Итальянские, французские, грузинские (Topical Authority) |
| K3 кофе | Кофе в турке, латте-арт | V60/Chemex/Aeropress, эспрессо |
| K4 чай | Китайский | Японская церемония, матча, пуэр-сет |

Это даёт **тематический авторитет** Google (Topical Authority) и забирает узкие хвосты от агрегаторов.

## Что НЕ делать

- ❌ Не удалять и не переписывать существующие продуктовые URL — потеряем ссылочный вес. Только усиливать контент.
- ❌ Не перегружать страницы стоковыми изображениями — Google и Яндекс распознают, это снижает E-E-A-T.
- ❌ Не пытаться вписать все 50 запросов кластера в одну страницу — переоптимизация. На странице 1 главный + 5-7 LSI.
- ❌ Не добавлять HowTo schema — Google убрал rich-результаты с сентября 2023.
- ❌ Не добавлять FAQPage только ради schema, если ответы шаблонные — Google теперь штрафует за манипулятивный FAQ. Только реальные вопросы и развёрнутые ответы.
